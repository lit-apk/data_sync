# Xiaomi wearable SDK

Place Xiaomi's proprietary wearable SDK here with this filename:

```text
xms-wearable-lib_1.4_release.aar
```

The resulting path must be:

```text
watch_data_sync/app/libs/xms-wearable-lib_1.4_release.aar
```

The APK builds without the AAR for UI development, but it cannot discover the
watch or exchange messages until the SDK is packaged into the APK.
